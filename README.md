# Code-Nova-GitHub-Training
Code Nova's GitHub Desktop training assignment

## About This Repository

This repository was created to practice using GitHub and GitHub Desktop. It demonstrates the basic Git workflow, including making commits, creating branches, merging changes, and pushing updates to GitHub.

## GitHub Skills Practiced

- Creating and publishing a repository
- Making multiple commits
- Creating and working with branches
- Merging a branch into main
- Pushing changes to GitHub
